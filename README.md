# baseball-data-api

先攻・後攻の両チームを対象に、試合中のプレーと過去の成績を登録する野球記録アプリの設計資料です。試合、打席、投球をたどり、球場・投手の投球腕・球種・コース・スイングの有無で投球を振り返れることを目指します。

## 設計ドキュメント

| 読みたい内容 | ドキュメント |
| --- | --- |
| 両軍のスタメン、打席・走塁・交代、試合後の確認、過去成績の入力手順 | [試合を記録する](docs/scorekeeping.md) |
| 1球ごとの入力、投手別の持ち球の選択・追加、ゾーンぎりぎりの球 | [投球を記録する](docs/pitch-tracking.md) |
| プレーと選手成績の関係、記録が一部しかない試合、年度集計の二重計上防止 | [データモデルと集計](docs/data-model.md) |
| 画面ごとのエンドポイント、投球の登録・検索例、訂正・再送の扱い | [API設計案](docs/api.md) |

## 合意した範囲と現在地

- **試合中**は両チームの打順と投手を引き継ぎ、打席結果、走者の移動、選手交代を記録する。1球ごとの球種・コース・打者の反応も入力できる。
- **過去の記録**は試合単位と年度合計の両方を扱う。最終スコアだけの試合、決め球だけ判明した打席も登録対象にする。集計には対象範囲ごとに採用元を一つ選ぶ。
- **投球入力**では投手の持ち球から選び、新しく確認した球種をその場で追加する。コースは捕手視点で記録でき、ゾーン境界の内外が判別できない場合も保存する。

画面操作は会話内のデモで試作した段階です。このリポジトリに収録しているのは設計資料で、APIサーバーとDB永続化は未実装です。PostgreSQLの論理構成、URL・フィールド名は実装に向けた案です。境界付近とする帯の幅や大会ごとの競技設定は、実装時に確定します。

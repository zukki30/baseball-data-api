# 試合の記録と過去成績の入力

対象は、先攻・後攻の両チームを記録するスコアブック。初期はNPBの終了済み試合と過去成績を扱い、本人がスコアブックやWebページを確認しながら手入力する。プレーを一度入力し、打者・投手双方の記録と試合内の状態に反映する。手元の資料に合わせて試合単位または年度単位の合計も入力する。本書は画面・操作の設計案。会話内の試作は一部の操作を試すためのもので、リポジトリに動作するアプリは含まれていない。

## 記録する試合を作成する

試合日、年度・大会や試合区分、先攻・後攻のチーム、球場を設定する。詳細が分かる資料では両チームの先発打順と先発投手を登録する。記録画面の上部には、入力済みのプレーから求めた両軍の得点、回と表裏、アウト数、各塁の走者を表示する。打席入力欄には現在入力している打順・打者と相手投手を表示し、打席が完了するとアプリがそのチームの打順を進め、次打者を自動表示する。

選手交代は試合内で発生した順序に登録する。代打は該当する打順、代走は該当する打順と塁上の走者、継投は守備側の投手を更新する。交代前の打席・投球には、そのときに出場していた選手を残す。打席途中の継投ではカウントを引き継ぎ、投球は実際に投げた投手に結び付ける。

出典の名称・URL・資料内の位置などを試合に添え、同じ資料を使う打席・投球へ引き継げる形を提案する。個別の記録に別の資料を使った場合は、その出典も残せるようにする。

## 試合内の出来事を入力する

| 場面 | 記録者が選ぶ内容 | 記録後の動作 |
| --- | --- | --- |
| 打席が完了した | 打席結果、打者・各走者の到達先やアウト、必要な打点 | 得点・アウト数・塁上を更新し、攻撃側の打順を一つ進める |
| 打席の途中で走者が動いた | 盗塁・盗塁死などの種類、対象走者と到達先 | 走者・得点・アウト数を更新する。打席が続けば同じ打者の入力に戻る |
| 3アウトになった | 最後のプレーと、そのプレーで認められた得点 | 試合が続けば攻守を交代する。次の攻撃は、そのチーム自身の次打者から始める |
| 記録を訂正する | 対象の打席またはプレーと正しい内容 | 直前の入力は取り消せる。過去の訂正では以後の塁・アウト・打順も再確認する |

打席結果には、単打・二塁打・三塁打・本塁打、三振、四球、死球、犠打、犠飛、失策出塁、野手選択などを用意する。「単打」を選ぶと打者の一塁到達を候補にできるが、一塁走者が二塁で止まったか、三塁まで進んだかは記録者が指定する。得点した走者と打点が付く打者は別に扱う。第3アウトがあるプレーでは、走者が本塁に到達した情報だけで得点を確定しない。

例として、3回表1死一塁で3番打者が三振すると、2死一塁で4番の打席になる。その途中で一塁走者が盗塁死した場合、4番の打席は未完了のため打席数に加えない。3回裏は後攻チームの次打者から始まり、4回表に先攻チームの4番が改めて打席に入る。

## 入力した記録を確認する

記録者は最終得点と両チームの選手別成績を照合する。完了した打席から安打や四死球を集計し、投球回は盗塁死など打席外で取得したアウトも含めて確認する。登板した投手が残した走者を救援投手が生還させた場合などは、失点の責任投手と自責点を確認する。勝利投手・敗戦投手・セーブなどの判断を要する項目は、資料や記録者の判定で補完する。

終了済みの試合にも、転記途中のデータがある。そこで、実際の試合状態とアプリでの記録状態を別々に持つ案とする。試合状態が終了済みでも記録状態は下書きにでき、資料との照合後に記録を確認済みにする。確認済みでも本人が誤入力を訂正できるようにする。記録が確認済みであることと、全打席・全投球の資料が揃っていることは別に管理する。

## 過去成績を登録する

| 手元にある資料 | 入力方法 | 利用できる集計 |
| --- | --- | --- |
| 過去のスコアブック | 過去日付の試合を作り、通常と同じ手順で打席・走塁を入力 | 記録した打席の一覧、試合成績、年度成績 |
| 1試合の結果・ボックススコア | 試合を選び、両軍の最終得点と判明した選手の打撃・投手成績を入力。最終得点だけでも登録できる | 判明した範囲の試合結果・選手成績 |
| 選手の年度成績表 | 年度・大会やリーグ・所属チーム・選手を指定し、打撃／投手の合計値を入力 | 年度・通算成績。月別・対戦相手別の内訳は試合資料がある範囲に限る |

空欄は「資料なし」、数値の `0` は「記録が0」を表す。たとえば最終得点が3対0でも、個人記録が分からなければ打数や安打は空欄のままにする。同じ選手・同じ対象範囲の試合成績と年度合計が揃った場合、どの値を集計に使うかを決めて二重計上を防ぐ。

## 個人・チーム・リーグを絞り込み、比較する

個人・チーム・リーグごとの閲覧と比較を提供することが確定した。以下の画面配置とフィルターは、その目的を実現する初期案である。

| 画面 | 操作と表示 |
| --- | --- |
| 個人成績 | 選手を選び、年度・期間・所属・試合区分を絞る。複数選手や同じ選手の複数年度を並べる |
| チーム成績 | チームの試合結果と打撃・投球成績を表示し、複数チームや年度を比較する |
| リーグ成績 | 対象リーグに属するチーム・選手の記録を集計し、リーグ間や年度間で比較する |
| 投球分析 | 球種・コース・投球腕・打席左右・カウント・スイング・判定で絞り、件数や率、分布を表示する |

比較画面は共通の条件を上部に置き、対象を追加すると同じ列で成績と対象件数を並べる案とする。自身の所属チーム・リーグと対戦相手のチーム・リーグを指定できると、リーグをまたぐ対戦も調べられる。打撃と投球で「自身」が指す側を明示する。

入力した一部の試合を集計した場合は、対象件数とともに「入力済みデータの集計」と表示する。率には分子・分母を添え、資料が不足する項目には不明であることを示す。年度合計を採用した成績と、詳細が判明した投球の分析では、それぞれの対象範囲を表示する。

## 閲覧と編集

本人が入力・編集し、他の人へ閲覧を許可できることが確定した。閲覧者には検索・絞り込み・比較を提供する。閲覧用の共有方法は、招待や公開リンクなどから今後選ぶ。

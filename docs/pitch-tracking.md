# 1球ごとの投球記録

両チームの各打席で、投手が投げた球種、通過したコース、打者が振ったか、投球結果を記録する。NPBの終了済み試合・過去資料を本人が確認して入力する。持ち球はその投手が使用したことを確認できる球種を候補にし、新たに使用を確認した球種もその場で追加して、今入力している球に使えるようにする。以下の項目名と保存方法は設計案。コース入力デモの帯幅は試用のための値である。

## 打席画面で1球を登録する

1. 入力対象の打者・打席左右、投手・投球腕、投球前カウントを表示する。直前から同じ選手なら入力を引き継ぐ。
2. 球種を選び、捕手から見たコースをタップする。球種や位置を判別できなければ、その項目を空欄にできる。
3. 「見逃しボール」「見逃しストライク」「空振り」「ファウル」「インプレー」などから結果を選ぶ。結果からスイングの有無が決まる場合は1回の選択で両方を入力する。「振った」ことだけ判明した場合も保存できる。
4. 「この球を記録」で保存する。打席が終了した場合は、同じ投球に打席結果と走者の動きを関連づける。例えば「インプレー」は投球結果、「中前安打」は打席結果であり、安打数は打席結果から1回加算する。

途中で継投した場合は同じ打席を継続し、交代後の球から実際に投げた選手・投球腕を切り替える。投球腕は右・左・不明のいずれか。両投げは選手プロフィール上の属性として扱い、個々の球には実際の腕を記録する。投球時点の打者と打席左右も保持する。四球などの公式記録が交代前の投手に付く場合も、その打席の各球について誰が投げたかを追跡できる。

## 持ち球候補を追加・選択する

例えば山田投手の候補に「ストレート」「スライダー」があり、資料から初めて「カットボール」の使用を確認した場合、球種欄の「球種を追加」から共通一覧のカットボールを選ぶ。**「持ち球に追加してこの球に使う」** を押すと入力中の球種がセットされ、次球以降の候補にも表示される。登録情報が不十分な過去資料でも、資料に記載された球種をその球に指定できる設計とする。

| 保存対象 | 役割 |
| --- | --- |
| 球種マスター | 共通の球種IDと表示名。共通一覧にも存在しない球種を作る場合は名称と別名の重複を確認する。 |
| 投手と球種の関連 | 選択候補。投手IDと球種IDの組を一意にし、同時に追加しても候補は1件になる。 |
| 投球記録 | 実投手と、その球で選んだ球種IDを保持する。後で候補から外れても、過去に投げた球種を参照できる。 |

「追加してこの球に使う」は持ち球への追加と入力欄での選択までを行う。コースや投球結果など入力中の内容を保持し、カウントは「この球を記録」で投球を保存したときに更新する。古い資料で球種が判明した場合、入力日や初めて記録した日から習得日は推定しない。「球種不明」は個々の球で `null` とし、候補には追加しない。

持ち球への追加・修正は本人が行い、閲覧者は登録された候補や記録を参照する。使用を確認した資料、対象年・試合などを候補に関連付ける案とする。投球データにある出典も確認の根拠に使える。ある年度の使用記録は、その年度の確認事実として保持する。過去の各球には、その球について資料から判断できた球種を記録する。

過去年度の入力では、候補に確認できた年度や出典を添えると選択しやすい。資料が不足する球は球種不明で保存できる。候補の表示順や、対象年度での使用確認に応じた絞り込みは実装時に調整する。

## コースと境界付近の記録

デモでは捕手視点のゾーン図をタップする。API・DB共通の正規化座標では、ゾーン左辺を `x=0`、右辺を `x=1`、上辺を `y=0`、下辺を `y=1` とする。ゾーンの外側もタップでき、例えば `(1.04, 0.2)` は右辺より外の高めを表す。値を0〜1に丸めると外れた距離が失われるため、そのまま保存する。内角・外角で表示する場合は打者が実際に立った打席左右を使う。

| 項目 | 値と意味 |
| --- | --- |
| `x`, `y` | タップ位置。位置を特定できない資料では両方 `null`。 |
| `isBorderline` | 境界付近なら `true`、離れていれば `false`、不明なら `null`。 |
| `zoneSide` | ゾーン内は `INSIDE`、外は `OUTSIDE`、線上は `ON_LINE`、内外判別不能は `null`。ここでいう内外は打者の内角・外角とは別。 |
| 実際の判定 | 見逃しストライク・ボールなどを独立して記録。位置と判定の組み合わせをそのまま分析できる。 |

過去資料に「きわどい見逃しストライク」とだけある場合、`isBorderline=true`、`zoneSide=null`、座標は空欄、結果は見逃しストライクとする。**内外が分からない場合に線上とは記録しない。** デモで境界付近を示す帯幅は内側・外側にそれぞれゾーン横幅の9%を取った仮値。本番で幅を決める場合は分類の定義・バージョンを残す。MLBの **Shadow Zone** は公式の Attack Zones の分類であり、このデモの帯幅を用いた独自分類には「境界付近」と表示する。

## 部分記録と分析の分母

打席ごとに「全球記録」「一部のみ」「球情報なし」を区別する。過去資料に「決め球は外角スライダーで空振り」とだけあれば、最終球として1件を登録し、実際の打席内球番と投球前カウントは `null` にできる。入力順と実際の球番を別に持つ。打席結果しか分からない場合は投球行を作らない。球を投げずに申告敬遠したと確認できる場合は、実投球0球として区別する。

「外角スライダーのスイング率」は**同じ球**にコース・球種の条件を適用し、スイング有無が判明した該当球を分母にする。振った7球／判明20球なら35%。空振り率を「スイングのうち空振りした割合」とする場合、接触の有無が判明したスイングを分母にする。通常の全球分析と、結果球を中心に記録した部分データの分析は対象範囲を切り替え、母数と不明件数を併記する。試合合計・年度合計のみの記録からは、球種・コース別の内訳を推定しない。
